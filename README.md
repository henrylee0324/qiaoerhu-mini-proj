# 巧兒護：臨托即時派單平台

資訊管理課 mini project（2026-11-04 課堂 10 分鐘報告）。

## 檔案

- `requirement.txt`：課程專案要求與評分標準
- `巧兒護企畫書_臨托即時派單平台.docx`：企畫書（含 VPC、BMC、定價、市場、AI 參與軌跡）
- `巧兒護_landing.html`：landing page，含可互動的派單示範，直接用瀏覽器開啟即可
- `巧兒護_prototype.html`：Demo 用原型。家長端與保母端並排，中間是派單引擎事件流。空白鍵或 → 下一步、← 上一步、R 重置；「模擬無人接單」開關示範擴大範圍與升級加急。網址加 `#s3` 可直接跳到第 3 步。純前端、示範資料，離線可開。
- `巧兒護_prototype_demo.gif`：原型七個步驟的備用動畫（每步 3 秒），投影機或網路出狀況時直接播放。

兩個 HTML 都已把 Noto Sans TC、Noto Serif TC、DM Sans 的子集字型內嵌（約 0.4 到 0.6 MB），不需網路也能顯示相同版面。

## 市場數字來源

臺北市民政局開放資料「臺北市各區人口數按年齡分」（data.gov.tw 資料集 132574，115 年 9 月）：大安區未滿 6 歲 10,418 人、含 6 歲 12,834 人；全市未滿 6 歲 82,717 人。企畫書情境以 10,418 計算。
